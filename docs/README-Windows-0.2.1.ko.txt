Imdev 0.2.1 — Windows x64 UI 개선 제안 테스트 빌드

이 화면 스타일은 사용자 확정안이 아니라 개발팀의 개선 제안입니다.
요청 편집과 응답 확인을 분리하고 간격/정렬/버튼/탭/색상 대비를 개선하는 버전입니다.
기본 다크 모드와 Harbor CSS 대비 텍스트 역할별 +1pt 정책을 유지합니다.
API 요청 동작과 저장·민감정보 보호 정책은 변경하지 않습니다.

실행 방법
1. ZIP을 '모두 압축 풀기'로 해제하세요.
2. Imdev 폴더의 imdev.exe를 더블클릭하세요.
3. Rust/Cargo/Node.js/Python을 설치할 필요가 없습니다.

Windows 10/11 x64 테스트용입니다. 실제 Windows에서의 실행·그래픽 드라이버·클립보드·한글 입력·네트워크 동작은 아직 확인하지 못했습니다. Windows ARM64 네이티브/32비트 빌드가 아닙니다. 그래픽 드라이버의 OpenGL 지원이 필요합니다.

파일은 Linux에서 크로스 빌드한 실제 PE32+ AMD64 Windows GUI 프로그램입니다. 소스 ZIP이나 Harbor 프로그램으로 대체한 것이 아닙니다. 미서명 테스트 빌드라서 SmartScreen 경고가 표시될 수 있습니다. 출처와 해시를 확인하고 조직 정책에 따라 실행하세요. 보안 기능을 끄거나 인터넷에서 임의 DLL을 내려받지 마세요.

화면 자료가 함께 전달된다면, 자료에 표시한 검증 범위를 확인하세요. egui 실제 UI의 메시/폰트 아틀라스를 소프트웨어로 그린 미리보기는 실제 Windows OS/GPU 화면 캡처와 다릅니다. 예시 응답은 로컬 mock HTTP 서버에서 받은 시험 데이터이며 실서비스 결과가 아닙니다.

보안/저장 정책
- 앱 시작 시 외부 API를 자동 호출하지 않습니다.
- 자동 재시도나 자동 redirect, TLS 인증 검증 해제는 하지 않습니다.
- 원본 요청/응답과 비밀값은 자동 저장하지 않습니다.
- 저장 템플릿은 origin만 남기고 URL 경로/쿼리/헤더 값/본문을 제거합니다. 불러온 후 다시 입력해야 합니다.
- 템플릿 이름과 query/header 키 이름은 평문 저장되므로 비밀정보를 넣지 마세요.
- 기본 저장 위치: %LOCALAPPDATA%\Imdev\state.json
- 같은 저장 폴더를 공유하는 앱은 하나만 실행하세요.

이상 동작이 있으면 Windows 버전과 경고·오류 문구, 창 크기 및 문제 위치를 알려주세요. URL/토큰/응답 내용의 민감정보를 제거한 뒤 보내세요. 이전 0.2.0 배포본은 변경하지 않았습니다.

licenses 폴더도 실행 파일과 함께 보관하세요.
